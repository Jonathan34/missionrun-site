# missionrun-site

The missionrun website: a single static page (`index.html`) published with GitHub Pages. No build step, no
JavaScript, no external requests.

Screenshots live in `screens/` (copied from the app repo's `docs/assets/readme/`); `favicon.svg` is the "Orbit m" mark and `og.png` is
the social preview. A demo video, when there is one, goes in `screens/demo.webm` and needs `media-src 'self'` in the CSP.
